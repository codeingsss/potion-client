Meteor Client 기반, 애드온(BeanShell/Python) 스크립팅으로 기능을 직접 확장하는 유틸리티 클라이언트

Features

스크립팅 애드온

BeanShell(.bsh)로 가볍게, 또는 Python Addon을 설치하면 진짜 Python(.py)으로도 나만의 모듈/명령어를 직접 만들 수 있습니다.

Potion 탭

ClickGUI에 추가된 전용 Potion 탭에서 애드온을 켜고 끄고, 새로 만들고, 폴더를 바로 열 수 있습니다.

모듈 제어 API

애드온 스크립트에서 다른 모듈을 켜고 끄거나 상태를 조회할 수 있어 기존 모듈과 자유롭게 조합해 확장할 수 있습니다.

Meteor Client 기반

실제 Meteor Client 소스를 포크해서 만들어졌습니다 — Combat, Movement, Render, World 등 익숙한 모든 모듈을 그대로 사용할 수 있습니다.

.jar 다운로드

설치: 다운로드한 .jar 파일(들)을 Fabric Loader가 설치된 .minecraft/mods 폴더에 넣고 실행하세요.

애드온 만들기

// example.bsh — BeanShell (기본 내장, 항상 작동)
myFeatureHandler() {
    run() {
        po.chat("Hello from my addon!");
    }
    return this;
}

po.set("Potion", "my-feature", (Runnable) myFeatureHandler());

# example.py — Python (Python Addon 설치 시 작동)
import Potion as po

def hello():
    po.chat("Hello from a Python addon!")

po.set("Potion", "python-hello", hello)

// example.c — Native (컴파일해서 .dll/.so, Native Addon 설치 시 작동)
#include <jni.h>

// .dll/.so가 로드되는 순간 자동으로 호출됩니다.
JNIEXPORT jint JNICALL JNI_OnLoad(JavaVM *vm, void *reserved) {
    JNIEnv *env;
    (*vm)->GetEnv(vm, (void **)&env, JNI_VERSION_1_8);

    jclass cls = (*env)->FindClass(env, "meteordevelopment/meteorclient/scripting/PotionNative");
    jmethodID chat = (*env)->GetStaticMethodID(env, cls, "chat", "(Ljava/lang/String;)V");

    jstring msg = (*env)->NewStringUTF(env, "Hello from a native addon!");
    (*env)->CallStaticVoidMethod(env, cls, chat, msg);

    return JNI_VERSION_1_8;
}

애드온 파일은 클라이언트 폴더의 meteor-client/addons/에 넣으면 됩니다. 게임 내 Potion 탭에서 켜고 끌 수 있습니다.

BeanShell 콜백 패턴

BeanShell은 함수를 값으로 바로 못 넘기기 때문에, 인터페이스 메서드 이름(run/accept)과 같은 이름의 중첩 함수를 만들고 그 스코프를 반환해야 합니다.

myHandler() {
    run() {                 // Runnable용 (set, command)
        po.chat("Hi!");
    }
    return this;
}
po.set("Potion", "my-feature", (Runnable) myHandler());

myArgHandler() {
    accept(args) {           // Consumer<String>용 (commandWithArgs)
        po.chat("You said: " + args);
    }
    return this;
}
po.commandWithArgs("say", (java.util.function.Consumer) myArgHandler());

외부 Python 패키지 사용

Python Addon 설치 시, 클라이언트 폴더의 meteor-client/addons/.potion_lib/site-packages/ 폴더가 자동으로 Python 경로에 포함됩니다. 본인 컴퓨터에 설치된 Python으로 순수 Python 패키지를 그 폴더에 설치하면 addon 스크립트에서 바로 import할 수 있습니다. C/네이티브 확장이 필요한 패키지(numpy 등 일부)는 GraalPy 특성상 동작하지 않을 수 있습니다.

pip install --target "C:\...\meteor-client\addons\.potion_lib\site-packages" requests

네이티브(C/C++) 애드온 작성법

Native Addon 설치 시, meteor-client/addons/의 .dll(Windows)/.so(Linux)/.dylib(macOS) 파일이 공유 라이브러리로 로드됩니다. 별도의 init/tick 콜백 규약은 없고, 표준 JNI 진입점인 JNI_OnLoad가 로드 즉시 한 번 호출됩니다 — 여기서 원하는 대로 스레드를 만들거나 아래 함수들을 호출하면 됩니다. BeanShell/Python과 달리 샌드박스가 전혀 없는 네이티브 코드이므로, 신뢰할 수 있는 애드온만 설치하세요.

클래스: meteordevelopment/meteorclient/scripting/PotionNative. 반환 타입에 맞는 JNI 호출 함수를 쓰세요 — V→CallStaticVoidMethod, Ljava/lang/String;→CallStaticObjectMethod, Z→CallStaticBooleanMethod, F→CallStaticFloatMethod, I→CallStaticIntMethod, D→CallStaticDoubleMethod, J→CallStaticLongMethod. set/command/commandWithArgs/java는 콜백 함수를 받기 때문에 네이티브 애드온에서는 지원하지 않습니다 — 모듈/명령어가 필요하면 BeanShell/Python을 쓰세요.

컴파일 방법

JDK의 include 폴더에 있는 jni.h/jni_md.h 헤더가 필요합니다. 결과물(.dll/.so)을 meteor-client/addons/에 넣으면 됩니다.

# Windows (MinGW gcc)
gcc -shared -I"%JAVA_HOME%\include" -I"%JAVA_HOME%\include\win32" -o example.dll example.c

# Linux
gcc -shared -fPIC -I"$JAVA_HOME/include" -I"$JAVA_HOME/include/linux" -o example.so example.c

# macOS
clang -shared -I"$JAVA_HOME/include" -I"$JAVA_HOME/include/darwin" -o example.dylib example.c
