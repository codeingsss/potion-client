Potion Client

Meteor Client 기반, 애드온(BeanShell/Python) 스크립팅으로 기능을 직접 확장하는 유틸리티 클라이언트

Minecraft 1.21.11 · Fabric · GPL-3.0

Features

스크립팅 애드온

BeanShell(.bsh)로 가볍게, 또는 Python Addon을 설치하면 진짜 Python(.py)으로도 나만의 모듈/명령어를 직접 만들 수 있습니다.

Potion 탭

ClickGUI에 추가된 전용 Potion 탭에서 애드온을 켜고 끄고, 새로 만들고, 폴더를 바로 열 수 있습니다.

모듈 제어 API

애드온 스크립트에서 다른 모듈을 켜고 끄거나 상태를 조회할 수 있어 기존 모듈과 자유롭게 조합해 확장할 수 있습니다.

Meteor Client 기반

실제 Meteor Client 소스를 포크해서 만들어졌습니다 — Combat, Movement, Render, World 등 익숙한 모든 모듈을 그대로 사용할 수 있습니다.

.jar 다운로드

설치: 다운로드한 .jar 파일(들)을 Fabric Loader가 설치된 .minecraft/mods 폴더에 넣고 실행하세요.

애드온 만들기

// example.bsh — BeanShell (기본 내장, 항상 작동)
myFeatureHandler() {
    run() {
        po.chat("Hello from my addon!");
    }
    return this;
}

po.set("Potion", "my-feature", (Runnable) myFeatureHandler());

# example.py — Python (Python Addon 설치 시 작동)
import Potion as po

def hello():
    po.chat("Hello from a Python addon!")

po.set("Potion", "python-hello", hello)

애드온 파일은 클라이언트 폴더의 meteor-client/addons/에 넣으면 됩니다. 게임 내 Potion 탭에서 켜고 끌 수 있습니다.
